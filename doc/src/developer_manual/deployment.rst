Dependencies

Depending on the solver you want to use.

********************
Installation of MOLA
********************

* Source the solver environment.
* Use the command `pip3 install mola-workflow --target=<INSTALL_PATH>`

You have to do this with each solver that you want to use, each time with a different `<INSTALL_PATH>`

Another option is to download sources from the GitLab or GitHub repository, and add MOLA to you PYTHONPATH.
