VISU MODULE

Collection of routines and functions designed for visualization techniques.

File history: 12/06/2020 - v1.8.01 - L. Bernardos - Creation

MOLA.Visu.makeAnimation(Frames, WidthPixels=700, FrameWildCard='Frame*', delay=10, OutputFilename='Animation.gif', RemoveFramesAtEnd=True)¶

Make an animated gif file using a set of previously saved frames.

Parameters

  • Frames (list of str) – List of paths where frames are located

  • WidthPixels (int) – Width pixels of final movie (keeping aspect ratio)

  • FrameWildCard (str) – Wildcard used for detecting the frame files

  • delay (float) – delay between frames

  • OutputFilename (str) – final file produced by this function

  • RemoveFramesAtEnd (bool) – if True, systematically remove Frames after movie creation

MOLA.Visu.xyz2Pixel(points, win, posCam, posEye, dirCam, viewAngle)¶

Returns the two-component image-pixel positions of a set of points located in the 3D world of CPlot.

Parameters

  • points (list of 3 float tuple) – \((x,y,z)\) coordinates of points in 3D world

  • win (tuple of 2 int) – Window resolution in pixels

  • posCam (tuple of 3 float) – position of Camera (see CPlot doc)

  • posEye (tuple of 3 float) – position of eye (see CPlot doc)

  • dirCam (tuple of 3 float) – direction of Camera (see CPlot doc)

  • viewAngle (float) – angle of Camera (see CPlot doc)

Returns

width, height – width and height in pixels using the convention of origin located at upper left side of image

Return type

tuple of 2 float
